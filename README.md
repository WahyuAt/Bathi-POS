# Aplikasi Point of Sale (PoS) – Demo Offline

Aplikasi PoS berbasis **HTML, CSS, dan JavaScript murni**. Tidak membutuhkan server atau instalasi database untuk demo. Semua data disimpan di **localStorage browser**.

## Fitur utama
1. Dashboard
2. Kasir
3. Produk
4. Stok
5. Pelanggan
6. Pembayaran
7. Struk
8. Kas / Shift
9. Laporan Penjualan
10. User Management

## Cara menjalankan
- Ekstrak file ZIP.
- Buka `index.html` dengan Chrome / Edge / Firefox.
- Login menggunakan akun demo.

### Akun demo
- Admin: `admin` / `admin123`
- Kasir: `kasir` / `kasir123`

## Catatan
Versi ini adalah prototype offline yang cocok untuk demo, pembelajaran, dan validasi alur bisnis. Password disimpan lokal sebagai teks biasa, sehingga **belum layak untuk produksi**. Untuk produksi, gunakan backend/API, autentikasi aman, database seperti PostgreSQL/MySQL, hashing password, audit log, backup, dan kontrol akses sisi server.
